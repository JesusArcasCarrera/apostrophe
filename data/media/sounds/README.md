# Typewriter sound sources

All samples in this directory are derived from CC0 recordings published on
OpenGameArt.org.

## Key presses

- Source: **Keyboard Soundpack #1 [Typing and Single Keystrokes]**
- Author: unicaegames
- URL: https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes
- Recording: Cherry KC 1000 keyboard with a Shure SM7B microphone
- License: CC0 1.0

The `classic`, `soft`, and `electric` profiles use different single-key
recordings from this pack. They have been trimmed, downmixed where necessary,
equalized, and normalized to profile-specific levels.

## Return sounds

- Source: **Typewriter sounds**
- Author: Cassie-OrbitGames
- URL: https://opengameart.org/content/typewriter-sounds
- License: CC0 1.0

Three recordings from this collection are used as the distinct return sounds.
They have been trimmed, downmixed, equalized, and normalized.
